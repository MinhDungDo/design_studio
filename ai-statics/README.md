# AI Statics — MVP

Direct-response static ad generator. **One ICP → one ad per awareness stage**, all
images generated by **Higgsfield's DTC Ads Engine** (no LLM in the loop).

## Architecture

```
Next.js App
  └── /app/api/generate/route.ts     ← reads BRIEF.md, uploads refs, streams the swarm (NDJSON)
        └── lib/agents/
              ├── orchestrator.ts      ← fans out across awareness stages, streams progress
              ├── promptBuilder.ts     ← BRIEF.md + offer + awareness stage → image brief
              ├── higgsfield.ts        ← `higgsfield` CLI client (upload, ad-formats, dtc-ads, brand-kits)
              └── awareness.ts         ← the 5 awareness stages + per-stage briefs
  └── /app/api/formats/route.ts        ← lists DTC ad formats for the picker

content/BRIEF.md                       ← internal brand + ICP creative brief, injected into every prompt
convex/                                ← brand-asset image library (_storage)
```

**Pipeline:** product image(s) + offer + ad format → for each awareness stage,
`dtc-ads generate` produces a branded ad (copy baked in by Higgsfield) → streamed live.

## Quickstart

### 1. Higgsfield CLI auth
The app shells out to the `higgsfield` CLI, which carries its own auth:
```
higgsfield auth login
```

### 2. Convex (brand-asset backend)
```
npx convex dev
```
Copy the printed URL into `.env.local`:
```
NEXT_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud
```

### 3. Fill in the brief
Edit `content/BRIEF.md` with the brand, the ONE ICP, and visual direction. Its text
is injected verbatim into every generation prompt.

### 4. Run
```
npm install
npm run dev
```
Open http://localhost:3000 — upload reference images, write an offer, pick a format and
stages, generate.

## Higgsfield commands we use
(Kept here, NOT in BRIEF.md, so they never leak into a generation prompt.)
- `higgsfield upload create <file> --json` → media id for a reference image
- `higgsfield marketing-studio ad-formats list --type headline --json` → the lane styles
- `higgsfield marketing-studio brand-kits fetch --url <store> --wait --json` → brand kit id
- `higgsfield marketing-studio dtc-ads generate --prompt <brief> --format-id <id> --media <id>:image [--brand-kit-id <id>] --wait --json` → one ad

## Cost
- Each awareness-stage lane is one billable Higgsfield job. `SWARM_CONCURRENCY` caps parallelism.
- Dev: keep `--quality low`/`--resolution 1k` (defaults in `higgsfield.ts`); bump for finals.
- Preview cost without generating: add `--cost-only` to a `dtc-ads generate` call.

## Notes
- No LLM / API keys: Higgsfield's backend writes the copy and prompt.
- `virality_predictor` is video-only, so there's no automated image scorer.
